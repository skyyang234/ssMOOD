# 新闻动态

## 版本对照表

下表展示**运行版本**（面向用户的发布号）与底层**代码库版本**（核心实现）的对应关系。
该对照有助于保证研究的可复现性，并便于追踪每次软件发布所使用的代码库。

```markdown
| 运行版本 | 代码库版本 | 发布日期 | 说明 |
| --------------- | ---------------- | ------------ | -------------------- |
| v2.0.0（当前） | v4.9.0 | 2026-11-08 | 最新版本 |
| v1.1.1 | v4.8.0 | 2026-03-07 | 第三次发布 |
| v1.1.0 | v4.7.0 | 2025-08-27 | 第二次发布 |
| v1.0.0 | v4.6.0 | 2025-07-06 | 首个正式版本 |

```

* **运行版本**：软件界面或发布说明中显示的版本号。
* **代码库版本**：核心分析引擎的内部开发版本。
* **说明**：发布状态的简要描述。

---
## V2.0.0
这是一次重大的前端发布，全面更新了平台的用户界面。它为每个页面带来一致的视觉风格，新增两个总览页面，重建了主页，并重新设计了整合数据集的呈现方式。所有数据接口与分析流程保持不变。

* **全站一致的视觉风格**：统一了配色、字体、间距以及按钮、表格和卡片的外观，每个页面都呈现简洁现代的观感。
* **新增 Browse 与 About 页面**：新增两个总览页面——**Browse** 页展示所有可用数据类型（单细胞 RNA-seq、空间转录组及即将推出的模块）和开发路线图；**About** 页汇集文档、新闻、访问统计与联系方式。
* **重建主页**：主页重新设计，新增横幅区域（包含细胞簇动画插图）、更清晰的布局，重复访问时访问统计加载更快。
* **导航栏与页脚改进**：重组顶部导航菜单，用新版页脚替换旧版页脚，显示平台运行版本。
* **整合数据集浏览重新设计**：单细胞与空间转录组页面的整合数据集现在以清晰的总览卡片呈现（替代原先在图上叠加按钮的形式）。每张卡片包含描述、关键数字（物种、脑区、实验条件）和快捷导航按钮——小鼠研究显示全部样本、实验条件（0D Control、3D、7D、Susceptible、Resilient），人类研究显示脑区与诊断分组（如 BA46 → 2 Control / 2 MDD）——直达对应的整合研究视图。
* **加载体验提升**：新增品牌化加载屏，站点就绪时平滑淡出，避免首次加载时内容突兀切换。
* **多语言文案更新**：扩展英、简体中文、繁体中文的界面文案，覆盖所有新页面与组件。
* **稳定性改进**：修复整合研究页在子集切换间不刷新的问题，优化页面滚动行为。

## V1.1.1
本次发布包含界面优化和若干缺陷修复，提升稳定性与用户体验。

* **界面优化**：优化单细胞与空间转录组数据以及整合数据集的展示界面，在数据探索时引入图表间联动交互。
* 更新了下载页的下载链接。
* **缺陷修复**：
修复在空间转录组整合数据集视图中点击 (0-day) 数据时发生的错误。
修复打开 Methods 页面时的渲染失败问题。
修复空间转录组请求数据获取时的错误。

## V1.1.0

本版本着重提升平台的稳定性、易用性与可访问性。

* **模块优化**：优化 *差异表达（DE）* 与 *基因集富集* 模块的展示与动态响应。
* **热图健壮性**：增强数组边界保护，提升稳定性，避免渲染错误。
* **语言支持**：改进英文翻译，并新增基于浏览器默认设置的自动语言选择。
* **文档**：集成站内文档，引导用户使用核心功能。

---

## V1.0.0

本版本带来一系列重大改进与新功能，重点在性能、易用性与分析能力。

* **可视化一致性**：图表配色与对应发表论文一致，保证结果一致。
* **差异表达分析**：新增排序功能，结果解读更清晰。
* **导航增强**：实现高级分页组件，提高 DE 与基因集富集结果的浏览效率。
* **交互式图例**：重新设计图例，实现 UMAP/ST 空间图与基因表达图的联动交互。
* **功能富集**：完成三项 Gene Ontology（GO）富集分析。
* **用户体验提升**：引入加载屏与图表动画占位，避免数据处理期间的空白状态。
* **性能优化**：提升图表渲染效率，优化热图可视化的清晰度。
* **代码维护**：解决多条警告信息，构建更干净、运行更稳定。
* **数据集整合**：完成数据集整合模块，空间转录组（ST）数据集独立视图展示。
