# 新聞動態

## 版本對照表

下表展示**運行版本**（面向用戶的發布號）與底層**代碼庫版本**（核心實現）的對應關係。
該對照有助於保證研究的可復現性，並便於追蹤每次軟體發布所使用的代碼庫。

```markdown
| 運行版本 | 代碼庫版本 | 發布日期 | 說明 |
| --------------- | ---------------- | ------------ | -------------------- |
| v2.0.0（當前） | v4.9.0 | 2026-11-08 | 最新版本 |
| v1.1.1 | v4.8.0 | 2026-03-07 | 第三次發布 |
| v1.1.0 | v4.7.0 | 2025-08-27 | 第二次發布 |
| v1.0.0 | v4.6.0 | 2025-07-06 | 首個正式版本 |

```

* **運行版本**：軟體介面或發布說明中顯示的版本號。
* **代碼庫版本**：核心分析引擎的內部開發版本。
* **說明**：發布狀態的簡要描述。

---
## V2.0.0
這是一次重大的前端發布，全面更新了平台的用戶介面。它為每個頁面帶來一致的視覺風格，新增兩個總覽頁面，重建了主頁，並重新設計了整合資料集的呈現方式。所有資料介面與分析流程保持不變。

* **全站一致的視覺風格**：統一了配色、字體、間距以及按鈕、表格和卡片的外觀，每個頁面都呈現簡潔現代的觀感。
* **新增 Browse 與 About 頁面**：新增兩個總覽頁面——**Browse** 頁展示所有可用資料類型（單細胞 RNA-seq、空間轉錄組及即將推出的模組）和開發路線圖；**About** 頁彙集文件、新聞、訪問統計與聯絡方式。
* **重建主頁**：主頁重新設計，新增橫幅區域（包含細胞簇動畫插圖）、更清晰的佈局，重複訪問時訪問統計載入更快。
* **導覽列與頁尾改進**：重組頂部導覽選單，用新版頁尾替換舊版頁尾，顯示平台運行版本。
* **整合資料集瀏覽重新設計**：單細胞與空間轉錄組頁面的整合資料集現在以清晰的總覽卡片呈現（替代原先在圖上疊加按鈕的形式）。每張卡片包含描述、關鍵數字（物種、腦區、實驗條件）和快捷導覽按鈕——小鼠研究顯示全部樣本、實驗條件（0D Control、3D、7D、Susceptible、Resilient），人類研究顯示腦區與診斷分組（如 BA46 → 2 Control / 2 MDD）——直達對應的整合研究視圖。
* **載入體驗提升**：新增品牌化載入畫面，站點就緒時平滑淡出，避免首次載入時內容突兀切換。
* **多語言文案更新**：擴充英、簡體中文、繁體中文的介面文案，覆蓋所有新頁面與元件。
* **穩定性改進**：修復整合研究頁在子集切換間不重新整理的問題，最佳化頁面滾動行為。

## V1.1.1
本次發布包含介面最佳化和若干缺陷修復，提升穩定性與用戶體驗。

* **介面最佳化**：最佳化單細胞與空間轉錄組資料以及整合資料集的展示介面，在資料探索時引入圖表間聯動互動。
* 更新了下載頁的下載連結。
* **缺陷修復**：
修復在空間轉錄組整合資料集視圖中點擊 (0-day) 資料時發生的錯誤。
修復打開 Methods 頁面時的渲染失敗問題。
修復空間轉錄組請求資料獲取時的錯誤。

## V1.1.0

本版本著重提升平台的穩定性、易用性與可訪問性。

* **模組最佳化**：最佳化 *差異表達（DE）* 與 *基因集富集* 模組的展示與動態響應。
* **熱圖健壯性**：增強陣列邊界保護，提升穩定性，避免渲染錯誤。
* **語言支援**：改進英文翻譯，並新增基於瀏覽器預設設定的自動語言選擇。
* **文件**：整合站內文件，引導用戶使用核心功能。

## V1.0.0

本版本帶來一系列重大改進與新功能，重點在效能、易用性與分析能力。

* **視覺化一致性**：圖表配色與對應發表論文一致，保證結果一致。
* **差異表達分析**：新增排序功能，結果解讀更清晰。
* **導覽增強**：實現高級分頁元件，提高 DE 與基因集富集結果的瀏覽效率。
* **互動式圖例**：重新設計圖例，實現 UMAP/ST 空間圖與基因表達圖的聯動互動。
* **功能富集**：完成三項 Gene Ontology（GO）富集分析。
* **用戶體驗提升**：引入載入畫面與圖表動畫佔位，避免資料處理期間的空白狀態。
* **效能最佳化**：提升圖表渲染效率，最佳化熱圖視覺化的清晰度。
* **代碼維護**：解決多條警告訊息，構建更乾淨、運行更穩定。
* **資料集整合**：完成資料集整合模組，空間轉錄組（ST）資料集獨立視圖展示。
